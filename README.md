# AI Novel Factory

장편 웹소설의 기획, 참고작 분석, 연속 집필, 품질 검수와 출판 준비를 한곳에서 관리하는 관리자 대시보드 프로토타입입니다.

## 실행

별도 빌드 과정 없이 정적 파일로 실행할 수 있습니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 포함된 기능

- 작품·회차 진행 현황 대시보드
- AI 집필 파이프라인 상태 표시
- 참고 작품별 분석 상태 및 구조 참고 강도
- 장기 기억, 복선, 타임라인 상태 요약
- 회차별 품질 검사 결과
- 새 작품 생성 모달과 반응형 사이드바
